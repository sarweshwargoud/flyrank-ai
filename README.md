# FlyRank Backend Internship

This repository contains my work, assignments, and projects completed during the **FlyRank Backend Development Internship**.

The projects focus on learning backend development fundamentals through hands-on implementation using modern frameworks and best practices.

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
- Git & GitHub

## Repository Structure

```
week1/
week2/
week3/
...
```

Each week's folder contains the source code, documentation, and any related resources for that assignment.

## Running a Project

Navigate to the required week's folder and install the dependencies.

```bash
pip install -r requirements.txt
```

Start the FastAPI server.

```bash
uvicorn main:app --reload
```

The application will be available at:

```
http://127.0.0.1:8000
```

Interactive API Documentation:

```
http://127.0.0.1:8000/docs
```
